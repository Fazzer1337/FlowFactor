FlowFactor - десктопный калькулятор производственных цепочек по игре Factorio.
Расчётную информацию брал с https://wiki.factorio.com/Main_Page/ru

Программа позволяет рассчитывать цепочки производства, потребление ресурсов, топлива и электроэнергии, а также визуализировать зависимости в виде дерева и графа.
Возможности:
учёт сырья, топлива и электропотребления
расчёт производственных цепочек для заданных игроком целей;
поддержка разных машин (сборщики, печи, буры);
сохранение и загрузка конфигураций (JSON-пресеты).

Визуализация:
дерево зависимостей;
граф производственных потоков.

Используемые технологии:
C# / .NET 8;
WPF (MVVM);
JSON для хранения пресетов.

Назначение:
Проект создан в рамках лабораторной работы, как инженерный инструмент для анализа и планирования производств в игре Factorio.
